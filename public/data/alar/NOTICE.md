# Alar derived database notice

The JSON files in this directory are a machine-transformed snapshot of V. Krishna's **Alar Kannada–English Dictionary**.

- Source: https://github.com/alar-dict/data
- Source file: `alar.yml`, downloaded 17 October 2026
- Upstream publisher: V. Krishna / Alar
- Licence: Open Data Commons Open Database License 1.0 (ODC-ODbL 1.0)
- Licence text: https://opendatacommons.org/licenses/odbl/1-0/
- Transformation: Unicode NFC normalization, preservation of source entry IDs, phonetic notation, origin, notes and definitions, followed by grouping into Kannada-initial JSON shards.
- Derived snapshot: 156,650 entries; 139,991 distinct headword strings; 247,674 definitions.

These derived database files are offered under ODC-ODbL 1.0, not under the application's MIT licence. Application source code remains separately licensed. The corpus is general dictionary evidence and must not be represented as proof of regional usage, a complete inventory of living Kannada, or human-recorded pronunciation.
